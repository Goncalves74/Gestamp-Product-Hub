# Gestamp Product Hub — Mockup

Mockup navegável para demonstração do fluxo centralizado de informação do produto.

## Conteúdo

- Planificação Avançada numa página única;
- Modos consultar, criar nova peça e introduzir alteração;
- Vistas mínimas com campos obrigatórios;
- Planeamento, Árvore do Produto, Ficha Técnica e documentação;
- Fluxo de alterações para IT/SAP;
- Página da Qualidade com dados populados a partir da PA;
- Imagens fictícias 3D e real da peça para demonstração;
- Separadores navegáveis na página da Qualidade;
- Pedidos SAP e Dados Mestre.

Abra `index.html` num navegador ou publique a pasta pela raiz no GitHub Pages.

Todos os dados apresentados são fictícios e destinam-se apenas à demonstração.
